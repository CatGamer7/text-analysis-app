# text-analysis-app (Приложение для анализа текстовых данных языковыми моделями)
## Краткое описание
*Назначение*: Приложение предоставляет графический интерфейс для обработки пользовательских текстовых данных языковыми моделями. Встроенные модели заточены на анализ данных социальных медиа на русском и английском языках.
*Проблема*: Инструменты обработки текстовых данных социальных медиа, представленные языковыми моделями, крайне разнообразны: от больших генеративных моделей с few-shot инструкциями до компактных энкодерных моделей. Такие решения активно создаются специалистами в области обработки естественного языка и часто распространяются в виде файлов моделей и исходного кода в открытых репозиториях.
С другой стороны, при анализе данных социальных медиа, учёные-социологи полагаются на ограниченный круг инструментов с наличием пользовательского интерфейса, который позволил бы исследователю без специальных навыков произвести обработку данных. 
Отдельной проблемой является ограниченность моделей для обработки русскоязычных данных. Решения для русского языка с графическим интерфейсом, в основном, представлены платформами поддержки SMM, а не инструментами исследований. Тем не менее, существует и небольшое количество открытых моделей для обработки русского языка с программным интерфейсом.
В итоге, существует разрыв между передовыми технологиями обработки текстов и реально используемыми инструментами. Возникает потребность в графической оболочке, которая позволит социологам использовать более новые открытые модели для разных языков.

## Существующие решения для анализа текстов социальных медиа
1.	Специализированные платформы обработки текстов (прямые конкуренты):
1.1.	CrystalFeel – 2018 год, онлайн, основано на словарях, только английский язык.
1.2.	SENA – 2021 год, оффлайн, основано на словарях, только английский язык.
2.	Платформы поддержки исследований, охватывающие широкий спектр задач:
2.1.	Communalytic – 2025 год, онлайн платформа с подпиской, использует языковые модели, ограниченная поддержка русского языка.
2.2.	Медиалогия – 2010 год, онлайн платформа с подпиской, использует языковые модели, полная поддержка русского языка. Ориентировано на SMM, а не на исследователей.
3.	Сервисы с генеративными моделями и few-shot примерами, общими проблемами которых являются стоимость и особенно низкая интерпретируемость.

В результате, ниша предлагаемого решения состоит в предоставлении сфокусированного оффлайн приложения с поддержкой современных моделей для анализа уже извлечённых текстов на русском и английском языках.

## Цель
Создание десктопного приложения для анализа массивов текстовых данных с помощью фиксированного множества открытых языковых моделей.

## План
1.	Анализ потребностей исследователей в конкретных типах моделей, поиск доступных решений, выявление единого интерфейса входных/выходных данных.
2.	Создание модуля инференса языковой модели и окна апробации модели в пользовательском интерфейсе.
3.	Создание окна обработки массива текстов с получением выгрузки результатов, включая функционал паузы/продолжения и расчёта времени завершения.
4.	Создание окна визуализации и аналитики результатов.
5.	Создание окна интерпретации решений языковой модели методами XAI.

## Команда
-	Фронтенд-разработчик десктопного приложения (можно веб-интерфейс)
-	Бэкенд-разработчик десктопного приложения
-	ML инженер
-	UI дизайнер
-	Тестировщик

## Ожидаемый результат
Десктопное приложение с установщиком, которое имеет ряд функций:
-	Окно апробирования модели, где пользователь вводит короткий текст и получает его оценку конкретной моделью.
-	Окно обработки массива текстов, где пользователь задаёт входной файл, ожидает окончания обработки (включая расчёт времени завершения и механизм паузы/продолжения) и получает выходной файл с результатами.
-	Окно анализа результатов, которое строит агрегированные графики.
-	Окно интерпретации, которое объясняет решения модели при анализе данных.
